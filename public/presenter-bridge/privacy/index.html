English

What the app does

COMPASS Presenter Bridge is a Windows companion app. After an educator pairs it with an authorized, prepared lecture, it observes the slide currently displayed in a saved Microsoft PowerPoint presentation and synchronizes the corresponding PDF page in COMPASS Interactive.

On the device, the app reads the saved PPTX bytes to calculate a SHA-256 match value. Through PowerPoint desktop automation it also reads the file display name, slide IDs and order, slide and hidden-slide counts, slideshow mode and range settings, and the current slide. This local access is limited to matching the open presentation and following its page; the app does not read slide text or speaker notes.

Data sent to COMPASS

The app sends only the metadata needed to bind, secure, and update the lecture:

  • a public signing key and its fingerprint, request signatures, random nonces, and timestamps;
  • cryptographic hashes of the saved PPTX file and ordered PowerPoint slide IDs, plus slide and hidden-slide counts;
  • the current slide ID and index, corresponding PDF page, random event ID, and sequence number;
  • connection, lecture, document, installation, authorized educator and administrator-session identifiers, and lifecycle timestamps; and
  • short-lived pairing and connection credentials used to authenticate the session.

The hosting providers may process ordinary network information such as an IP address and user-agent. COMPASS stores a keyed hash derived from a trusted network identifier for short-lived rate limiting, rather than storing the raw address in its Presenter database table.

The app does not upload presentation content. It does not send the PPTX file, slide text, speaker notes, images, audio, video, local file path, hosted file name, PowerPoint or Microsoft account credentials, or student personal information. The local browser may receive the deck's display name over an exact-origin localhost session; that name is not included in hosted Presenter requests.

Why the data is used

The metadata verifies that the saved deck matches the lecture PDF, authenticates the installed app, prevents replayed or altered requests, updates the displayed page, and enforces ownership, expiry, rate, and safety controls. The publisher does not sell Presenter metadata or use it for advertising or model training.

Storage and retention

  • A connection record remains while the connection is active. After it has been revoked for 30 days, it and its lifecycle events become eligible for deletion by scheduled cleanup.
  • Replay-protection receipts expire after 10 minutes, and rate-limit buckets are deleted after 10 minutes without an update.
  • A small cleanup-health record retains aggregate operational times and backlog counts; it has no fixed deletion period.

Provider security logs, backups, and legally required copies may follow separate retention periods. Microsoft processes Store acquisition and may process usage, crash, and hang diagnostics under its own settings and privacy terms; the publisher may receive the reports Partner Center makes available. Store distribution uses Microsoft, the Presenter gateway and global network edge use Cloudflare, and the Edge Function and PostgreSQL service in the configured production region use Supabase. Network-edge and provider operations may process data outside Japan.

Data on the Windows device

A signing-only P-256 private key is stored as non-exportable key material in the current Windows user's CNG key store. Only the public key is sent. A connection capability is kept in process memory and is not restored after the app restarts. The browser locally stores the privacy-decision version and date for up to one year, one manual-mode digest, and up to 32 material-consent digests. These digests contain no presentation text. The manual and material digests remain until the educator uses the PowerPoint control to clear local Presenter data or clears this site's browser data. If that deletion cannot be completed, a content-free withdrawal safety marker is kept for up to one year in local or session storage and a Strict same-site first-party cookie so another tab cannot reconnect with the withdrawn decision. Clearing this site's browser data removes that marker.

Security

Hosted requests use a fixed HTTPS endpoint and are signed by the local key. Random nonces, timestamps, one-way credential hashes, expiry and replay checks protect each connection. Presenter database tables deny direct browser access; the authorized service path performs ownership checks before it can read or change Presenter records.

Your choices and requests

Before the first hosted inspection on a browser profile, the educator receives a short in-product explanation and expressly enables the PowerPoint connection. An educator can later stop synchronization, disconnect, rescind that permission, and clear the browser's local Presenter preferences from the same PowerPoint control. The Bridge tray also provides an idle-only, confirmed action to remove the local signing key and connection identity; the next launch creates a new identity. Ending the lecture, revoking the authorized educator session, changing the bound document, or disabling the feature also ends the connection. To request access, correction, or deletion where applicable, contact contact@yuto-matsui.com. The publisher will use the minimum information needed to verify authority and identify the relevant lecture record.

Publisher, region and Microsoft Store

Yuto Matsui is the publisher and data contact for this Bridge-specific processing. The initial Store release is intended for Japan. Questions, complaints and applicable privacy-right requests can be sent to the address above. Microsoft handles Store account, acquisition and optional diagnostic data under the Microsoft Privacy Statement; that Store processing is separate from metadata sent by the Bridge to COMPASS.

日本語

アプリの役割

COMPASS Presenter BridgeはWindows用の補助アプリです。教員が、準備済みで権限のある講義と一度接続すると、保存済みMicrosoft PowerPointファイルで現在表示されているスライドを検出し、COMPASS Interactiveの対応するPDFページを同期します。

端末内では、保存済みPPTXのバイト列を読み取り、照合用SHA-256を計算します。PowerPointデスクトップ連携から、ファイル表示名、スライドIDと順序、スライド数と非表示数、スライドショーのモード・範囲設定、現在のスライドも読み取ります。このローカルアクセスは、開いている資料の一致確認とページ追従のために限定し、スライド本文や発表者ノートは読み取りません。

COMPASSへ送信するデータ

講義の対応付け、安全性、ページ更新に必要な次のメタデータだけを送信します。

  • 公開署名鍵とその指紋、リクエスト署名、ランダムなnonce、時刻
  • 保存済みPPTXファイルとPowerPointスライドID順序の暗号学的ハッシュ、 スライド数、非表示スライド数
  • 現在のスライドIDと位置、対応するPDFページ、ランダムなイベントID、連番
  • 接続、講義、文書、インストール、認証済み教員、管理者セッションの識別子とライフサイクル時刻
  • 接続を認証する短時間有効なペアリング情報と接続資格情報

ホスティング事業者は、IPアドレスやUser-Agentなど通常の通信情報を処理する場合があります。COMPASSのPresenter用データベースでは、生のアドレスではなく、信頼されたネットワーク識別子から導出した鍵付きハッシュを短時間のレート制御に保存します。

プレゼンテーションの内容はアップロードしません。 PPTXファイル、スライド本文、発表者ノート、画像、音声、動画、ローカルのファイルパス、ホスト先へのファイル名、PowerPointまたはMicrosoftアカウントの認証情報、学生の個人情報は送信しません。ローカルブラウザには、オリジンを限定したlocalhost接続でファイルの表示名を返す場合がありますが、ホスト先へのPresenterリクエストには含めません。

利用目的

メタデータは、保存済み資料と講義PDFの一致確認、インストール済みアプリの認証、改変・再送リクエストの防止、表示ページの更新、所有権・有効期限・レート・安全制御に利用します。発行者はPresenterのメタデータを販売せず、広告やモデル学習にも利用しません。

保存期間

  • 接続レコードは接続中に保持されます。失効後30日を経過すると、関連するライフサイクル記録とともに定期削除の対象になります。
  • 再送防止レシートは10分後に失効し、レート制御バケットは更新がない状態で10分経過後に削除されます。
  • 削除処理の実行時刻と滞留数だけを持つ小さな稼働確認レコードには、固定の削除期間を設けていません。

事業者のセキュリティログ、バックアップ、法令上必要な複製には別の保存期間が適用される場合があります。Microsoftは自社の設定とプライバシー条件に従ってStoreでの取得情報を処理し、利用状況、クラッシュ、停止診断を処理する場合があります。発行者はPartner Centerが提供する範囲でレポートを参照できます。Store配布にはMicrosoft、Presenter GatewayとグローバルなネットワークエッジにはCloudflare、Edge Functionと設定済みの本番リージョンで稼働するPostgreSQLサービスにはSupabaseを利用します。ネットワークエッジや事業者の運用により、日本国外で処理される場合があります。

Windows端末内のデータ

署名専用のP-256秘密鍵を、現在のWindows利用者のCNGキーストアへエクスポート不可の鍵として保存します。送信するのは公開鍵だけです。接続資格情報はプロセスのメモリに保持し、アプリ再起動後には復元しません。ブラウザには、最長1年間のプライバシー同意の版と日時、手動モードのdigest 1件、資料同意のdigest最大32件を保存します。これらにプレゼンテーション本文は含みません。手動モードと資料同意のdigestは、PowerPoint連携画面でローカルPresenterデータを削除するか、このサイトのブラウザデータを消去するまで保持します。削除を完了できない場合は、取り消した同意による別タブからの再接続を防ぐため、内容を含まない取消安全マーカーをlocal/session storageとStrictのsame-site first-party cookieに最長1年間保持します。このサイトのブラウザデータを消去すると、そのマーカーも削除されます。

安全管理

ホスト先へのリクエストは固定HTTPS endpointを使用し、端末内の鍵で署名します。ランダムなnonce、時刻、資格情報の一方向ハッシュ、有効期限、再送検査により接続を保護します。Presenter用テーブルへのブラウザからの直接アクセスは禁止し、権限のあるサービス経路が所有権を再確認してから記録を読み書きします。

停止・照会・削除

ブラウザで初めてホスト先への資料照合を行う前に、短い説明を表示し、教員がPowerPoint連携を明示的に有効にします。その後も、同じPowerPoint連携画面から同期停止、切断、同意の撤回、ブラウザ内のPresenter設定削除ができます。Bridgeのtrayには、待機中だけ利用できる確認付きの操作として、ローカル署名鍵と接続IDの削除を用意します。次回起動時には新しいIDを作成します。講義の終了、認証済み教員セッションの失効、資料の変更、機能の無効化でも接続は終了します。適用される範囲で開示、訂正、削除を希望する場合は、 contact@yuto-matsui.com へご連絡ください。発行者は、権限確認と対象講義記録の特定に必要な最小限の情報を利用します。

発行者・対象地域・Microsoft Store

このBridge固有の処理について、Yuto Matsuiが発行者およびデータ窓口です。Store初版は日本向けです。質問、苦情、適用されるプライバシー上の請求は上記窓口へご連絡ください。MicrosoftはStoreアカウント、取得、任意の診断情報を Microsoftプライバシーステートメントに基づき取り扱います。これはBridgeからCOMPASSへ送信するメタデータ処理とは別です。
