Registration is not required for a name or design to be protected. This policy
also applies to confusingly similar names, logos, domains, social accounts,
application identifiers, and product presentation.

## Uses that do not require separate permission

You may:

- refer to COMPASS Interactive accurately in commentary, research, education,
  news, or a technical review;
- link to the canonical repository or product site;
- state truthfully that a GitHub fork or proposed contribution is derived from
  COMPASS Interactive; and
- reproduce marks only when technically necessary to preserve attribution or
  show an unmodified screenshot for commentary.

These uses must be factual, limited, and must not imply sponsorship,
certification, partnership, origin, or approval.

## Uses that require written permission

Written permission is required to:

- use a Project Mark in the name, logo, domain, application identifier, social
  account, or primary branding of another product, service, organization, or

- distribute modified project artwork or a confusingly similar visual identity;
- use a Project Mark in advertising, merchandise, fundraising, certification,
  or commercial promotion; or
- present a fork, hosted service, integration, course, or publication as an
  official COMPASS Interactive offering.

The source license independently restricts production use, commercial use,
hosting, competing products, and redistribution. Trademark permission does not
waive or expand those restrictions.

## Forks and modifications

A GitHub fork may retain repository notices and factual references needed for
GitHub collaboration. It must not use Project Marks to suggest that the fork or
its operator is the canonical project. Any separately authorized distribution
or deployment must use distinct branding unless the rights holder gives
written permission.

Do not remove required copyright, license, notice, provenance, or attribution
statements. Third-party names and logos remain subject to their owners' terms.

For a permission request, open a public issue containing only the proposed use
and a non-confidential way to follow up. Do not include credentials, private
contracts, personal data, or unreleased product information.
