## 7. Supabase load and Advisor result

本番DBで`comments`が`supabase_realtime` publicationに存在しないことを確認した。学生側は5秒snapshot同期を使用し、コメントごとのPostgres Changes接続を作らない。

最終Security／Performance AdvisorはERROR 0で終了した。

残存WARN 3件はPhase 0の要件上、意図したAnonymous Auth利用に対する検知である。

- `comments`: open講義のvisible comment読み取り
- `lecture_display_state`: active display state読み取り
- `participants`: `auth.uid()`で所有する自分のparticipant読み取り

これらは無条件public accessではなく、講義状態または`auth.uid()`によるRLS制約を持つ。INFOの`RLS enabled, no policy`はdeny-by-default tableであり、現時点では意図した閉鎖状態である。unused index INFOは稼働直後で統計が十分でないため、削除せず実負荷計測後に再評価する。

## 8. Non-blocking operational follow-up

CloudflareのGit自動buildに使われる既存tokenは、PagesへのEdit権限不足によりdeploy stepが失敗する。今回の本番反映は、公式Wrangler OAuthのPages／Workers write権限を用いて成功しているため、Phase 0の本番bundle自体は正常である。

次のrelease前に、Cloudflare Git integration用tokenを最小権限のPages／Workers deploy権限で更新し、自動buildを再検証する。それまでは、検証済みcommitからの公式Wrangler手動deployをrelease手順とする。
