# Data Policy

COMPASS Interactive is designed to lower the psychological barrier to classroom participation. The application therefore avoids collecting personally identifying student data.

## Allowed in the Interactive App

- Anonymous `participant_id`
- `lecture_id`
- Anonymous comments
- Comment likes / upvotes
- Poll responses
- Quiz responses in a later phase
- Timestamps

## Not Collected in the Interactive App

- Student names
- Student IDs
- University email addresses
- Grades
- Detailed personal profiles
- Formal named lecture evaluations

## Post-Lecture Feedback

Named feedback, if needed, should be collected through Google Form and managed separately with GAS / Spreadsheet. The Interactive app may pass a lecture identifier to the form, but should not pass personally identifying student data.
